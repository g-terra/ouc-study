# semesters/

Your personal study data lives here, one folder per semester (e.g. `2026-Fall/`), created by `ouc setup`.
It holds OUC course materials, your submissions, grades and notes, so **everything in this folder except this README is git-ignored**. Never commit it or share it: course materials belong to OUC and their authors.

The format of `semester.json` is shown in `docs/semester.example.json`.
